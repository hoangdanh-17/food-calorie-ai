# Food Calorie AI

Hệ thống nhận diện thực phẩm và ước tính calorie bằng AI.

## Công nghệ
- Python
- PyTorch
- ResNet50
- Transfer Learning
- Food-101
- Streamlit

## Kết quả
- 101 lớp thực phẩm
- Top-1 Accuracy: 66.38%
- Top-5 Accuracy: 88.19%

## Chức năng
- Nhận diện món ăn từ ảnh
- Hiển thị độ tin cậy
- Ước tính calorie theo khẩu phần
